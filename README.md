# 🌍 MapQuiz

MapQuiz, kullanıcıların **harita, başkent ve bayrak bilgilerini** test edebileceği  
basit ve eğlenceli bir **web tabanlı quiz uygulamasıdır**.

Proje, **HTML, CSS ve JavaScript** kullanılarak geliştirilmiştir ve tarayıcı üzerinde çalışır.

---

## 🎯 Projenin Amacı

Bu projenin amacı:
- Coğrafya bilgisini eğlenceli hale getirmek
- Harita temelli quizlerle öğrenmeyi desteklemek
- Basit web teknolojileriyle etkileşimli bir uygulama geliştirmektir

---

## 🧠 Quiz Türleri

Projede farklı quiz türleri bulunmaktadır:

- 🗺️ **Harita Quiz**
- 🏳️ **Bayrak Quiz**
- 🏙️ **Başkent Quiz**

Kullanıcılar ana menüden istedikleri quiz türünü seçebilir.

---

## 📂 Proje Dosya Yapısı

```text
mapquiz/
├── index.html          # Ana menü / giriş sayfası
```
